# STM32 Bare Metal & Making Embedded Systems

A hands-on learning respository documenting my journey through **Elica White's - Making Embedded Systems**.

## Hardware & Toolchain

* **Dev Board** STM32 Nucleo-L476RG
* **Debugger/Programmer** On-board ST-LINK V2
* **Cross Compiler** `arm-none-eabi-gcc`
* **Build System** CMake
* **FLashing & Debugging** OpenOCD + `amr-none-ebai-gbd`
